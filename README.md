# 🔥 给策划烧纸 · EdgeOne Pages 部署包

一个文件，开箱即玩。整个游戏是**单个自包含 HTML**（Canvas 礼花 + Web Audio 合成音乐 + 掉落系统），无任何外部依赖，不需要服务器、数据库、构建步骤。

## 文件说明

| 文件 | 说明 |
|---|---|
| `index.html` | 游戏本体（已改名，部署后访问根路径即玩） |
| `README.md` | 本说明（上传后不影响游戏，可忽略） |

## 上传步骤（EdgeOne Pages 控制台）

1. 登录腾讯云 → 搜索「**EdgeOne Pages**」
2. 创建项目 → 选择「**静态站点**」
3. 部署方式选「**上传静态资源**」：
   - 把本文件夹**解压后整个拖进上传框**，或
   - 直接拖入 `edgeone-deploy.zip`（视控制台版本支持）
4. 部署完成后会得到 `https://xxx.edgeone.app` 域名，发给朋友点击即玩

## 可选：绑定自己的域名

在项目「自定义域名」里绑定一个已备案域名（如 `shaozhi.你的域名.com`），并按提示添加 CNAME 解析。

## 常见问题

- **没声音？** 浏览器要求用户先有交互才能出声 —— 点一下游戏（烧一张纸）即可解锁音乐和音效。
- **想用自己的歌当背景音乐？** 点游戏里的「本地 BGM」按钮，从手机/电脑里选一个音频文件即可。文件**不会上传**，只在本地播放，关掉页面即失效；点「✕ 停止」恢复内置音乐。
- **存档丢了？** 进度存在浏览器 `localStorage`，同一个域名下一直有效；换设备 / 清缓存 / 隐身模式会重置。
- **想改文案或掉落物？** 直接搜索 `index.html` 里的 `LOOT` 表，都是明文，改完重新上传即可。
- **长时间自动烧纸会不会卡？** 已做性能优化：移动端粒子自动减半、跑不动时自动开启低配模式、存档改为节流写入（每 4 秒最多一次）。如果还是很卡，可以关掉「自动烧纸」手动玩。
- **手机玩？** 支持触屏，点击 / 长按烧纸即可，无需额外适配。
